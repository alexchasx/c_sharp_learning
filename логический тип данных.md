# Подробный конспект о логическом типе данных в C#

#### 1. Основы типа `bool`

**Логический тип (`bool`)** — примитивный тип данных, который может принимать только два значения:
* `true` — истина;
* `false` — ложь.

Занимает в памяти 1 байт. Является псевдонимом для структуры `System.Boolean`.

**Объявление и инициализация переменных:**
```csharp
bool isActive = true;
bool hasPermission = false;
bool result; // неинициализированная переменная
```

#### 2. Инициализация значений

Способы присвоения значений:
* **Прямое присваивание:**
  ```csharp
  bool flag = true;
  ```
* **Результат сравнения:**
  ```csharp
  int age = 25;
  bool isAdult = age >= 18; // true
  ```
* **Результат логических операций:**
  ```csharp
  bool canVote = isAdult && hasCitizenship;
  ```
* **Вызов методов, возвращающих `bool`:**
  ```csharp
  string text = "Hello";
  bool isEmpty = string.IsNullOrEmpty(text); // false
  ```

#### 3. Логические операторы

Основные операторы, работающие с типом `bool`:

* **Логическое И (`&&`)** — возвращает `true`, если оба операнда `true`:
  ```csharp
  bool a = true && true;   // true
  bool b = true && false;  // false
  ```
* **Логическое ИЛИ (`||`)** — возвращает `true`, если хотя бы один операнд `true`:
  ```csharp
  bool c = true || false;  // true
  bool d = false || false; // false
  ```
* **Логическое НЕ (`!`)** — инвертирует значение:
  ```csharp
  bool e = !true;  // false
  bool f = !false; // true
  ```
* **Исключающее ИЛИ (`^`)** — возвращает `true`, если операнды различаются:
  ```csharp
  bool g = true ^ true;   // false
  bool h = true ^ false;  // true
  ```

#### 4. Операторы сравнения

Возвращают значение типа `bool`:
* `==` — равно;
* `!=` — не равно;
* `>` — больше;
* `<` — меньше;
* `>=` — больше или равно;
* `<=` — меньше или равно.

**Примеры:**
```csharp
int x = 5, y = 10;
bool eq = x == y;     // false
bool neq = x != y;   // true
bool gt = x > y;     // false
bool lt = x < y;     // true
bool gte = x >= 5;  // true
bool lte = y <= 10; // true
```

#### 5. Условные конструкции с `bool`

Логические значения активно используются в управляющих конструкциях:

* **`if-else`:**
  ```csharp
  bool isLoggedIn = CheckLogin();
  if (isLoggedIn)
  {
      Console.WriteLine("Добро пожаловать!");
  }
  else
  {
      Console.WriteLine("Пожалуйста, войдите в систему.");
  }
  ```
* **`while`:**
  ```csharp
  bool continueLoop = true;
  while (continueLoop)
  {
      // код
      continueLoop = CheckCondition();
  }
  ```
* **`do-while`:**
  ```csharp
  do
  {
      // код
  } while (userWantsToContinue);
  ```
* **`for`:**
  ```csharp
  for (int i = 0; i < 10 && isRunning; i++)
  {
      // код выполняется, пока i < 10 И isRunning == true
  }
  ```

#### 6. Тернарный оператор

Оператор `?:` возвращает одно из двух значений в зависимости от логического условия:
```csharp
bool isSunny = true;
string weather = isSunny ? "Солнечно" : "Пасмурно";
// weather = "Солнечно"

int number = 5;
string sign = number > 0 ? "Положительное" : "Отрицательное или ноль";
```

#### 7. Nullable-логический тип (`bool?`)

Тип `bool?` (или `Nullable<bool>`) может принимать три значения: `true`, `false` и `null`.

**Использование:**
```csharp
bool? unknownStatus = null;
bool? hasVoted = true;
bool? isConfirmed = false;
```

**Проверка значений:**
```csharp
if (unknownStatus == true)
{
    // выполнится, только если unknownStatus точно true
}
else if (unknownStatus == false)
{
    // выполнится, только если unknownStatus точно false
}
else
{
    // unknownStatus равен null
}
```

#### 8. Вспомогательные методы и свойства

Структура `System.Boolean` предоставляет полезные статические методы:
* `bool.Parse(string)` — преобразует строку в `bool`:
  ```csharp
  bool value1 = bool.Parse("true");  // true
  bool value2 = bool.Parse("false"); // false
  ```
* `bool.TryParse(string, out bool)` — безопасный парсинг:
  ```csharp
  if (bool.TryParse("invalid", out bool result))
  {
      // успешно преобразовано
  }
  else
  {
      // ошибка преобразования
  }
  ```
* `ToString()` — преобразует `bool` в строку:
  ```csharp
  Console.WriteLine(true.ToString());  // "True"
  Console.WriteLine(false.ToString()); // "False"
  ```

#### 9. Особенности и нюансы

* **Автоматическое преобразование:** в C# нет неявного преобразования между `bool` и другими типами (например, `int`). Код вида `if (1)` вызовет ошибку компиляции.
* **Короткое замыкание (`short-circuit evaluation`):** операторы `&&` и `||` вычисляют правый операнд только при необходимости:
  ```csharp
  bool result = false && SomeMethod(); // SomeMethod() не вызывается
  bool result2 = true || AnotherMethod(); // AnotherMethod() не вызывается
  ```
* **Приоритет операторов:** логические операторы имеют определённый приоритет выполнения. При сложных выражениях рекомендуется использовать скобки:
  ```csharp
  bool complex = a && b || c && d;
  // лучше записать как:
  bool clear = (a && b) || (c && d);
  ```

#### 10. Практические примеры использования

**Пример 1: проверка доступа**
```csharp
bool hasPassword = !string.IsNullOrEmpty(userPassword);
bool isValidLength = userPassword.Length >= 8;
bool containsDigit = userPassword.Any(char.IsDigit);

bool isStrongPassword = hasPassword && isValidLength && containsDigit;
if (isStrongPassword)
{
    Console.WriteLine("Пароль надёжный");
}
```

**Пример 2: управление циклом**
```csharp
bool continueGame = true;
while (continueGame)
{
    Console.WriteLine("Игра продолжается. Продолжить? (y/n)");
    string input = Console.ReadLine();
    continueGame = input.ToLower() == "y";
}
Console.WriteLine("Игра окончена.");
```

**Пример 3: фильтрация данных**
```csharp
List<int> numbers = new List<int> { 1, 2, 3, 4, 5, 6 };
var evenNumbers = numbers.Where(n => n % 2 == 0); // фильтрует чётные числа
```

---

**Краткий итог:**
* `bool` — фундаментальный тип для представления логических значений (`true`/`false`);
* активно используется в условиях, циклах и логических операциях;
* поддерживает стандартные логические и сравнительные операторы;
* имеет nullable‑версию (`bool?`) для работы с неопределёнными состояниями;
* требует явного указания условий — не допускает неявных преобразований из других типов;
* оптимизирован для производительности в условных конструкциях.

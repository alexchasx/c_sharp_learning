# Подробный конспект о типе целочисленных данных в C#

В C# целочисленные типы данных делятся на **знаковые** (могут хранить отрицательные и положительные числа) и **беззнаковые** (только неотрицательные числа).

#### 1. Знаковые целочисленные типы

| Тип | Размер (байт) | Диапазон значений | Особенности |
|---|---|---|---|
| `sbyte` | 1 | от $-128$ до $127$ | Наименьший знаковый целочисленный тип |
| `short` (System.Int16) | 2 | от $-32\,768$ до $32\,767$ | Короткое целое |
| `int` (System.Int32) | 4 | от $-2\,147\,483\,648$ до $2\,147\,483\,647$ | Наиболее часто используемый целочисленный тип |
| `long` (System.Int64) | 8 | от $-9\,223\,372\,036\,854\,775\,808$ до $9\,223\,372\,036\,854\,775\,807$ | Длинное целое, используется для больших чисел |

**Примеры объявления:**
```csharp
sbyte smallNumber = -100;
short mediumNumber = 30000;
int largeNumber = 1000000;
long veryLargeNumber = 9223372036854775807L; // суффикс L обязателен для long
```

#### 2. Беззнаковые целочисленные типы

| Тип | Размер (байт) | Диапазон значений | Особенности |
|---|---|---|---|
| `byte` | 1 | от $0$ до $255$ | Часто используется для работы с бинарными данными |
| `ushort` | 2 | от $0$ до $65\,535$ | Беззнаковое короткое целое |
| `uint` | 4 | от $0$ до $4\,294\,967\,295$ | Беззнаковое целое |
| `ulong` | 8 | от $0$ до $18\,446\,744\,073\,709\,551\,615$ | Беззнаковое длинное целое |

**Примеры объявления:**
```csharp
byte data = 200;
ushort positiveMedium = 50000;
uint positiveLarge = 3000000000U; // суффикс U обязателен для uint
ulong positiveVeryLarge = 18446744073709551615UL; // суффикс UL для ulong
```

#### 3. Суффиксы для литералов

Для явного указания типа целочисленного литерала используются суффиксы:
* `L` или `l` — для `long`;
* `U` или `u` — для `uint`, `ulong`;
* `UL` или `ul` — для `ulong`.

**Примеры:**
```csharp
long l = 1234567890123L;
uint u = 4294967295U;
ulong ul = 18446744073709551615UL;
```

#### 4. Основные операции с целочисленными типами

**Арифметические операции:**
```csharp
int a = 10, b = 3;
int sum = a + b;     // 13
int diff = a - b;    // 7
int product = a * b;  // 30
int quotient = a / b; // 3 (целочисленное деление)
int remainder = a % b; // 1 (остаток от деления)
```

**Инкремент/декремент:**
```csharp
int x = 5;
x++; // x = 6
x--; // x = 5
```

**Побитовые операции** (особенно актуальны для `byte` и `ushort`):
```csharp
byte a = 5;  // 00000101
byte b = 3;  // 00000011
byte and = (byte)(a & b);  // 1 (00000001)
byte or = (byte)(a | b);   // 7 (00000111)
byte xor = (byte)(a ^ b);  // 6 (00000110)
byte not = (byte)(~a);     // 250 (11111010)
```

#### 5. Преобразование типов

**Неявное преобразование** (автоматическое, без потери данных):
```csharp
int i = 100;
long l = i; // OK: int → long
byte b = 10;
int i2 = b; // OK: byte → int
```

**Явное преобразование** (требуется при возможном потере данных):
```csharp
long bigNumber = 1000;
int smallNumber = (int)bigNumber; // Явное приведение
byte tiny = (byte)smallNumber;   // Явное приведение
```

**Методы класса `Convert`:**
```csharp
string str = "123";
int fromString = Convert.ToInt32(str);
double d = 45.67;
int fromDouble = Convert.ToInt32(d); // округление до ближайшего целого
```

#### 6. Константы и вспомогательные свойства

Каждый целочисленный тип имеет статические поля:
* `MinValue` — минимальное значение типа;
* `MaxValue` — максимальное значение типа.

**Пример:**
```csharp
Console.WriteLine(int.MinValue); // -2147483648
Console.WriteLine(int.MaxValue); // 2147483647
Console.WriteLine(byte.MaxValue);  // 255
```

#### 7. Особенности и рекомендации

1. **Выбор типа:**
   * используйте `int` по умолчанию — он оптимален по производительности на большинстве платформ;
   * `long` — для очень больших чисел или работы с файловыми размерами, временными метками;
   * `byte`/`sbyte` — в сетевых протоколах, работе с файлами, криптографии;
   * беззнаковые типы — когда заведомо не нужны отрицательные значения и важен верхний предел.

2. **Производительность:**
   * на 32‑битных системах `int` и `uint` работают быстрее;
   * на 64‑битных — `long` и `ulong` могут быть эффективнее.

3. **Безопасность:**
   * проверяйте границы значений при преобразованиях;
   * используйте `checked` для контроля переполнения:
```csharp
checked
{
    int result = int.MaxValue + 1; // вызовет исключение OverflowException
}
```
   * или `unchecked` для подавления проверок (по умолчанию):
```csharp
unchecked
{
    int result = int.MaxValue + 1; // переполнение без исключения
}
```

4. **Литералы с разделителями** (C# 7.0+):
   * улучшенная читаемость больших чисел:
```csharp
int million = 1_000_000;
long big = 9_223_372_036_854_775_807L;
```

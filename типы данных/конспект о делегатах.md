# Подробный конспект о делегатах в языке C#

#### 1. Основы делегатов

**Делегат** — это тип, который представляет ссылки на методы с определённой сигнатурой (возвращаемым типом и параметрами). По сути, делегат — это **безопасный указатель на метод**.

**Ключевые особенности:**
* является ссылочным типом;
* строго типизирован (проверяется на этапе компиляции);
* может указывать на статические методы и методы экземпляра;
* поддерживает многоадресную подписку (multicast) — вызов нескольких методов одним делегатом;
* лежит в основе событий (events) в C#.

#### 2. Объявление делегатов

**Синтаксис объявления:**
```csharp
[модификатор_доступа] delegate возвращаемый_тип ИмяДелегата(параметры);
```

**Пример объявления:**
```csharp
public delegate void MessageDelegate(string message);
public delegate int Calculator(int a, int b);
```

#### 3. Создание и инициализация делегатов

**Способы создания:**

1. **Прямое создание:**
   ```csharp
   MessageDelegate del1 = new MessageDelegate(ShowMessage);
   ```
2. **Сокращённая форма (C# 2.0+):**
   ```csharp
   MessageDelegate del2 = ShowMessage;
   ```
3. **Анонимные методы (C# 2.0):**
   ```csharp
   MessageDelegate del3 = delegate(string msg) { Console.WriteLine(msg); };
   ```
4. **Лямбда‑выражения (C# 3.0+):**
   ```csharp
   MessageDelegate del4 = (msg) => Console.WriteLine(msg);
   Calculator calc = (a, b) => a + b;
   ```

**Полный пример:**
```csharp
void ShowMessage(string message)
{
    Console.WriteLine($"Сообщение: {message}");
}

// Использование
MessageDelegate myDelegate = ShowMessage;
myDelegate("Привет, мир!"); // Выведет: Сообщение: Привет, мир!
```

#### 4. Вызов делегатов

**Простой вызов:**
```csharp
MessageDelegate del = ShowMessage;
del("Тестовое сообщение"); // или del.Invoke("Тестовое сообщение")
```

**С обработкой `null`:**
```csharp
if (del != null)
    del("Безопасный вызов");
// Или с оператором ? (C# 6.0+)
del?.Invoke("Безопасный вызов");
```

#### 5. Многоадресные делегаты (Multicast)

Делегаты поддерживают объединение (операторы `+`/`+=`) и удаление (операторы `-`/`-=`) методов.

**Объединение делегатов:**
```csharp
MessageDelegate del1 = Method1;
MessageDelegate del2 = Method2;
MessageDelegate multicast = del1 + del2;
multicast("Сообщение"); // Вызовутся Method1 и Method2
```

**Добавление/удаление методов:**
```csharp
MessageDelegate multiDel = null;
multiDel += Method1; // Добавляем Method1
multiDel += Method2; // Добавляем Method2
multiDel("Сообщение"); // Оба метода вызовутся
multiDel -= Method1;  // Удаляем Method1
```

**Важные нюансы:**
* методы вызываются в порядке добавления;
* если метод возвращает значение, возвращается результат последнего вызванного метода;
* исключения в одном методе прерывают выполнение последующих.

#### 6. Встроенные делегаты

C# предоставляет готовые обобщённые делегаты:

* **`Action`** — для методов без возвращаемого значения:
  ```csharp
  Action<string> print = s => Console.WriteLine(s);
  Action<int, int> sum = (a, b) => Console.WriteLine(a + b);
  ```
* **`Func`** — для методов с возвращаемым значением:
  ```csharp
  Func<int, int, int> add = (a, b) => a + b;
  Func<string, int> length = s => s.Length;
  ```
* **`Predicate<T>`** — для предикатов (возвращает `bool`):
  ```csharp
  Predicate<int> isPositive = x => x > 0;
  ```

#### 7. Делегаты и события

Делегаты являются основой механизма событий в C#.

**Объявление события:**
```csharp
public event MessageDelegate OnMessageReceived;
```

**Использование:**
```csharp
class MessageSender
{
    public event MessageDelegate OnMessage;

    public void SendMessage(string message)
    {
        OnMessage?.Invoke(message);
    }
}
```

**Подписка на событие:**
```csharp
MessageSender sender = new MessageSender();
sender.OnMessage += ShowMessage; // Подписка
sender.SendMessage("Событие сработало!");
sender.OnMessage -= ShowMessage; // Отписка
```

#### 8. Методы делегатов

Основные методы класса `Delegate`:

* `GetInvocationList()` — возвращает массив всех подписанных методов;
* `DynamicInvoke()` — динамический вызов с параметрами в виде массива;
* `Method` — информация о методе;
* `Target` — объект, которому принадлежит метод (для методов экземпляра).

**Пример использования `GetInvocationList()`:**
```csharp
MessageDelegate multi = Method1 + Method2;
foreach (Delegate d in multi.GetInvocationList())
{
    Console.WriteLine($"Метод: {d.Method.Name}");
}
```

#### 9. Практические примеры

**Пример 1: калькулятор с делегатами**
```csharp
delegate double MathOperation(double a, double b);

double Add(double a, double b) => a + b;
double Multiply(double a, double b) => a * b;

MathOperation operation = Add;
Console.WriteLine(operation(5, 3)); // 8

operation = Multiply;
Console.WriteLine(operation(5, 3)); // 15
```

**Пример 2: сортировка с пользовательским компаратором**
```csharp
List<string> names = new List<string> { "John", "Alice", "Bob" };
names.Sort((x, y) => x.Length.CompareTo(y.Length));
// Сортировка по длине строки
```

**Пример 3: многоадресный делегат для логирования**
```csharp
Action<string> logger = LogToFile;
logger += LogToConsole;
logger += LogToDatabase;

logger("Ошибка произошла!"); // Все три метода выполнятся
```

#### 10. Делегаты в LINQ

Делегаты активно используются в LINQ‑запросах:

```csharp
List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };

// Where использует делегат Predicate<T>
var evenNumbers = numbers.Where(n => n % 2 == 0);

// Select использует Func<T, TResult>
var squares = numbers.Select(n => n * n);
```

#### 11. Важные нюансы и рекомендации

**Нюансы:**
* делегаты типобезопасны — сигнатура метода должна точно соответствовать делегату;
* при многоадресном вызове исключение в одном методе останавливает выполнение последующих;
* делегаты могут захватывать переменные из внешней области видимости (замыкания);
* многоадресные делегаты используют тип `System.MulticastDelegate`.

**Рекомендации:**
* используйте встроенные делегаты `Action`/`Func` вместо создания собственных, если это возможно;
* всегда проверяйте делегат на `null` перед вызовом;
* для событий используйте шаблон с проверкой `null` и копированием ссылки;
* учитывайте производительность — делегаты немного медленнее прямого вызова метода.

#### 12. Отличия от других механизмов

| Механизм | Когда использовать |
|--------|----------------|
| Делегаты | Когда нужно передать метод как параметр, реализовать callback, создать событие |
| Интерфейсы | Когда нужна полиморфная реализация с несколькими методами |
| Абстрактные классы | Когда нужна базовая реализация с возможностью расширения |

#### Краткий итог

* делегаты — это безопасный указатель на метод с заданной сигнатурой;
* поддерживают многоадресную подписку;
* являются основой событий в C#;
* имеют встроенные обобщённые версии (`Action`, `Func`, `Predicate`);
* широко используются в LINQ и асинхронном программировании;
* обеспечивают гибкость и расширяемость кода;
* требуют аккуратной работы с многоадресными вызовами и исключениями.

# Типы данных в языке C#

В C# типы данных делятся на несколько категорий:


#### 1. Значимые (value) типы

Хранятся в стеке, копируются по значению.

**Целочисленные типы:**
* `sbyte` — 8‑битовое целое со знаком: от $-128$ до $127$;
* `byte` — 8‑битовое целое без знака: от $0$ до $255$;
* `short` — 16‑битовое целое со знаком: от $-32\,768$ до $32\,767$;
* `ushort` — 16‑битовое целое без знака: от $0$ до $65\,535$;
* `int` — 32‑битовое целое со знаком: от $-2\,147\,483\,648$ до $2\,147\,483\,647$;
* `uint` — 32‑битовое целое без знака: от $0$ до $4\,294\,967\,295$;
* `long` — 64‑битовое целое со знаком: от $-9\,223\,372\,036\,854\,775\,808$ до $9\,223\,372\,036\,854\,775\,807$;
* `ulong` — 64‑битовое целое без знака: от $0$ до $18\,446\,744\,073\,709\,551\,615$.

**Типы с плавающей точкой:**
* `float` — 32‑битовый, точность 6–9 знаков: от $\pm1{,}5 \times 10^{-45}$ до $\pm3{,}4 \times 10^{38}$ (суффикс `f`/`F`);
* `double` — 64‑битовый, точность 15–17 знаков: от $\pm5{,}0 \times 10^{-324}$ до $\pm1{,}7 \times 10^{308}$ (суффикс `d`/`D`, можно опускать);
* `decimal` — 128‑битовый, высокая точность (28–29 знаков): от $\pm1{,}0 \times 10^{-28}$ до $\pm7{,}9 \times 10^{28}$ (суффикс `m`/`M`, подходит для финансовых расчётов).

**Прочие значимые типы:**
* `bool` — логическое значение: `true` или `false`;
* `char` — символ Unicode (16 бит): например, `'A'`, `'\u00A9'`;
* `enum` — перечисление (пользовательский тип);
* `struct` — структура (пользовательский составной тип).

#### 2. Ссылочные (reference) типы

Хранятся в управляемой куче (heap), копируются по ссылке.

* `string` — неизменяемая последовательность символов Unicode;
* `object` — базовый тип для всех типов в C#;
* `dynamic` — тип с отложенной проверкой типа (во время выполнения);
* массивы (`int[]`, `string[]` и т. д.);
* классы (`class`) — пользовательские ссылочные типы;
* интерфейсы (`interface`);
* делегаты (`delegate`) — типы для хранения ссылок на методы;
* кортежи (`(int, string)`) — начиная с C# 7.0.

#### 3. Указатели (unsafe context)

Используются в небезопасном коде (`unsafe`).

* `type*` — указатель на значение типа `type` (например, `int*`);
* `void*` — универсальный указатель.

#### 4. Специальные и составные типы

* **Nullable‑типы** (`T?`) — позволяют присваивать `null` значимым типам:
  ```csharp
  int? nullableInt = null;
  bool? unknown = null;
  ```
* **Анонимные типы** — создаются компилятором на основе инициализатора:
  ```csharp
  var person = new { Name = "Alice", Age = 30 };
  ```
* **Кортежи** — группы значений разных типов:
  ```csharp
  (int Id, string Name) tuple = (1, "Alice");
  ```

#### 5. Обобщённые типы (generics)

Позволяют создавать типы с параметризованными типами данных:
```csharp
List<T>
Dictionary<TKey, TValue>
```

### Краткий обзор по категориям

| Категория | Примеры | Особенности |
|--------|--------|-------------|
| Целочисленные | `int`, `long`, `byte` | Целые числа разного размера и знака |
| С плавающей точкой | `float`, `double`, `decimal` | Дробные числа с разной точностью |
| Логический | `bool` | `true` / `false` |
| Символьный | `char` | Один символ Unicode |
| Строковый | `string` | Последовательность символов, неизменяемая |
| Базовый ссылочный | `object` | Родитель всех типов |
| Динамический | `dynamic` | Проверка типа во время выполнения |
| Массивы | `int[]`, `string[,]` | Коллекции фиксированного размера |
| Коллекции | `List<T>`, `Dictionary<K,V>` | Обобщённые контейнеры |
| Пользовательские | `class`, `struct`, `enum`, `interface` | Определяются программистом |
| Специальные | `Nullable<T>`, кортежи, анонимные типы | Расширяют возможности типизации |

### Важные нюансы

* **Неявная типизация:** ключевое слово `var` позволяет компилятору вывести тип переменной из инициализатора (но тип всё равно фиксируется на этапе компиляции).
* **Преобразования:** C# поддерживает неявные и явные преобразования типов (приведение типов).
* **Строгая типизация:** компилятор проверяет типы на соответствие, предотвращая многие ошибки.
* **Размер типов** фиксирован в C# (в отличие от C/C++), что обеспечивает переносимость кода.

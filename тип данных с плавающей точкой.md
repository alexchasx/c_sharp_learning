# Подробный конспект о типах данных с плавающей точкой в C#

В C# существуют три основных типа данных с плавающей точкой, соответствующие стандарту IEEE 754. Они различаются по размеру в памяти, диапазону значений и точности.

#### 1. Основные типы данных с плавающей точкой

| Тип | Размер (байт) | Точность | Диапазон значений | Особенности |
|---|---|---|---|---|
| `float` | 4 | 6–9 значащих цифр | от $\pm1{,}5 \times 10^{-45}$ до $\pm3{,}4 \times 10^{38}$ | Одинарная точность, суффикс `f`/`F` |
| `double` | 8 | 15–17 значащих цифр | от $\pm5{,}0 \times 10^{-324}$ до $\pm1{,}7 \times 10^{308}$ | Двойная точность, по умолчанию для дробных литералов |
| `decimal` | 16 | 28–29 значащих цифр | от $\pm1{,}0 \times 10^{-28}$ до $\pm7{,}9 \times 10^{28}$ | Высокая точность, для финансовых расчётов, суффикс `m`/`M` |

#### 2. Объявление и инициализация

**Примеры:**
```csharp
float temperature = 25.5f;
double price = 19.99;
decimal salary = 50000.50m;

// Литералы с экспонентой
float scientific = 1.23e-4f; // 0.000123
double largeNumber = 2.5E+10; // 25 000 000 000
```

#### 3. Суффиксы для литералов

* `f` или `F` — для `float`;
* `d` или `D` — для `double` (можно опускать);
* `m` или `M` — для `decimal`.

**Пример:**
```csharp
float f = 3.14f;
double d1 = 3.14;    // без суффикса
double d2 = 3.14d; // с суффиксом
decimal dec = 3.14m;
```

#### 4. Специальные значения

Типы с плавающей точкой могут представлять особые значения:

* **Бесконечности:** `PositiveInfinity`, `NegativeInfinity`;
* **Не число (NaN)** — результат некорректных операций.

**Работа со специальными значениями:**
```csharp
double positiveInf = double.PositiveInfinity;
double negativeInf = double.NegativeInfinity;
double notANumber = double.NaN;

// Проверка
bool isInf = double.IsInfinity(positiveInf); // true
bool isNaN = double.IsNaN(notANumber);       // true
```

#### 5. Константы и вспомогательные свойства

Каждый тип имеет статические поля:
* `MinValue` — минимальное положительное значение;
* `MaxValue` — максимальное значение;
* `Epsilon` — наименьшее положительное значение.

**Пример:**
```csharp
Console.WriteLine(float.MinValue);  // -3.4028235E+38
Console.WriteLine(double.MaxValue); // 1.7976931348623157E+308
Console.WriteLine(decimal.Epsilon);  // 1E-28
```

#### 6. Основные операции

Все арифметические операции поддерживаются стандартно:
```csharp
double a = 10.5, b = 3.2;
double sum = a + b;      // 13.7
double diff = a - b;     // 7.3
double product = a * b;  // 33.6
double quotient = a / b; // 3.28125
```

**Важно:** при делении на ноль для `float` и `double` не возникает исключения — возвращается `Infinity` или `NaN`.

#### 7. Преобразование типов

**Неявное преобразование:**
```csharp
int intValue = 100;
double doubleValue = intValue; // int → double
float floatValue = intValue;  // int → float
```

**Явное преобразование:**
```csharp
double bigDouble = 123.456;
float smallFloat = (float)bigDouble;
int fromDouble = (int)bigDouble; // усечение дробной части
```

**Методы класса `Convert`:**
```csharp
string str = "123.45";
double fromString = Convert.ToDouble(str);
decimal fromDouble = Convert.ToDecimal(bigDouble);
```

#### 8. Точность и ошибки округления

**Проблема точности:** числа с плавающей точкой не всегда точно представляются в двоичной форме.

**Пример проблемы:**
```csharp
double a = 0.1;
double b = 0.2;
double c = a + b;
Console.WriteLine(c == 0.3); // false!
Console.WriteLine(c);       // 0.30000000000000004
```

**Решение:** сравнение с допуском (эпсилон):
```csharp
double epsilon = 1e-10;
bool areEqual = Math.Abs(c - 0.3) < epsilon; // true
```

#### 9. Форматирование вывода

Методы форматирования чисел:
```csharp
double number = 1234.56789;

Console.WriteLine(number.ToString("F2"));   // "1234.57" — 2 знака после запятой
Console.WriteLine(number.ToString("N"));   // "1,234.57" — с разделителем тысяч
Console.WriteLine(number.ToString("E2"));   // "1.23E+003" — научный формат
Console.WriteLine($"{number:C}");           // "$1,234.57" — валюта
```

#### 10. Рекомендации по выбору типа

1. **`float`**:
   * когда важна экономия памяти (например, в графических приложениях);
   * для некритичных вычислений с невысокой точностью;
   * в научных расчётах, где высокая точность не требуется.

2. **`double`**:
   * тип по умолчанию для дробных чисел;
   * подходит для большинства математических вычислений;
   * используется в научных и инженерных расчётах.

3. **`decimal`**:
   * финансовые расчёты и денежные значения;
   * ситуации, где критична точность десятичных дробей;
   * бухгалтерские приложения и банковские системы.

#### 11. Особенности и предупреждения

* **Сравнение на равенство:** избегайте прямого сравнения `==` для `float`/`double`. Используйте допуск (эпсилон).
* **Производительность:** `decimal` медленнее, чем `float`/`double`, из‑за более сложной арифметики.
* **Переполнение:** при выходе за диапазон возвращается `Infinity`.
* **Потери точности:** при преобразовании `double` → `float` возможна потеря точности.
* **Литералы:** без суффикса дробные литералы всегда имеют тип `double`.

#### 12. Практические примеры

**Финансовый расчёт с `decimal`:**
```csharp
decimal price = 19.99m;
decimal taxRate = 0.08m;
decimal total = price * (1 + taxRate);
Console.WriteLine($"Total: {total:C}"); // "Total: $21.59"
```

**Научный расчёт с `double`:**
```csharp
double radius = 5.0;
double area = Math.PI * Math.Pow(radius, 2);
Console.WriteLine($"Area: {area:F2}"); // "Area: 78.54"
```

---

**Краткий итог:**
* в C# три типа с плавающей точкой: `float`, `double`, `decimal`;
* выбор типа зависит от требуемой точности и области применения;
* учитывайте проблемы точности при сравнении чисел;
* используйте суффиксы для явного указания типа литералов;
* для денежных расчётов всегда используйте `decimal`;
* проверяйте специальные значения (`Infinity`, `NaN`) при необходимости.
